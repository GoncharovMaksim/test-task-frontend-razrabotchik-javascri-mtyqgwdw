## 🏛 Архитектура и строгая иерархия компонентов
В строгом соответствии с требованиями ТЗ реализована следующая иерархия React-компонентов:

```
Page (контейнер страницы, управление мета-тегами)
├── Header (фейковый профиль пользователя, передаваемый через props)
├── Body (контейнер полезной нагрузки)
│   ├── [На странице /cards]:
│   │   └── CardList (принимает массив карточек через props)
│   │       └── Card (рендер карточки: 3D CSS flip-анимация, цитата, перевод)
│   └── [На странице /profile]:
│       └── EditView (форма редактирования профиля, принимает массив полей)
│           └── Field (рендер конкретного поля: число, строка, текст, дата, select, checkbox, radio)
└── Footer (фейковые контакты компании, передаваемые через props)
```

## 🧩 Форма профиля: 20 полей и продвинутая логика зависимостей

Форма профиля содержит ровно **20 типизированных полей**:
1. `fullName`: **строка** (ФИО сотрудника)
2. `email`: **строка** (Корпоративный email)
3. `phone`: **строка** (Контактный телефон)
4. `city`: **строка** (Город проживания)
5. `birthDate`: **дата** (Дата рождения)
6. `targetSalary`: **число** (Ожидаемая заработная плата, руб.)
7. `experienceYears`: **число** (Опыт коммерческой разработки в годах)
8. `primaryRole`: **выпадающий список** (Основная специализация)
9. `englishLevel`: **выпадающий список** (Уровень владения английским языком)
10. `employmentType`: **группа radiogroup** — **[Поле А: управляющее]**
11. `officeCity`: **выпадающий список** — **[Поле Б: зависимое, скрываемое]**
12. `mentorshipRequired`: **выпадающий список** — **[Поле В: зависимое, блокируемое с предустановкой]**
13. `workFormat`: **группа radiogroup** (Формат работы)
14. `skills`: **группа checkbox-ов** (Стек технологий)
15. `education`: **выпадающий список** (Уровень образования)
16. `currentTraining`: **строка** (Текущее обучение и совмещение)
17. `githubUrl`: **строка** (Ссылка на GitHub)
18. `portfolioProjectsCount`: **число** (Количество завершенных проектов)
19. `preferredNotificationTime`: **выпадающий список** (Удобное время для связи)
20. `aboutBio`: **текст / textarea** (О себе и мотивация)

### Логика связывания полей (Продвинутый уровень):
- При выборе в **Поле А** (`employmentType`) значения **«Стажировка / Студент» (`intern`)**:
  - **Поле Б** (`officeCity`) автоматически **скрывается** (`hidden: true`)
  - **Поле В** (`mentorshipRequired`) становится **недоступным для редактирования** (`disabled: true`) и в него автоматически помещается предустановленное значение **«Обязательно требуется закрепленный ментор (Senior)»** (`mandatory`).
- При выборе любого другого типа занятости (Full-time / Part-time) Поле Б отображается, а Поле В разблокируется для ручного выбора.

## 🗂 Карточки для изучения иностранных слов
- Карточки содержат:
  - Мотивирующий заголовок (выбирается рандомно из предустановленного списка: *"Word of the Day"*, *"Level Up Your Vocabulary"*, *"Step to Fluency"* и др.)
  - Английское слово и транскрипцию
  - Пример использования
  - Кнопку действия **LEARN MORE**
- При клике по кнопке действия карточка плавно переворачивается с использованием **3D CSS анимации** (`transform: rotateY(180deg)` с сохранением перспективы) и отображает перевод, часть речи и перевод примера.
- При повторном клике по кнопке карточка переворачивается обратно на лицевую сторону.
- Доступна фильтрация по уровням владения (B1, B2, C1) и поиск по словам.

## 🛠 Технологический стек
- **Frontend Core:** React 18, TypeScript (strict mode)
- **State Management:** Redux Toolkit (`authSlice`, `cardsSlice`, `profileSlice`), React-Redux
- **Routing:** React Router DOM v6, Protected Routes
- **Styling:** Tailwind CSS (нейтральная темная тема в эстетике GitHub Dark / Linear)
- **Testing:** Vitest, React Testing Library, @testing-library/jest-dom (20 unit и integration тестов)
- **Mocking:** REST API Mock Service с имитацией задержки сети и сохранением в localStorage
- **Containerization:** Docker (Multi-stage build), Docker Compose, Nginx
- **Deployment:** Vercel

## 🚀 Локальный запуск

### 1. Установка зависимостей:
```bash
npm install
```

### 2. Запуск в режиме разработки:
```bash
npm run dev
```
Приложение откроется по адресу: `http://localhost:5173`

### 3. Запуск тестов:
```bash
npm test
```

### 4. Сборка production бандла:
```bash
npm run build
```
